### 审查中修掉的问题（第一轮 → 第二轮）

1. **标题糊成白块**：华文彩云是空心字，18px 叠 2px 描边后完全不可读 → 全站标题改华文琥珀，描边只给大字号。
2. **品牌名太吵**：16px 艺术字挤在一起 → 回退无衬线 800 字重。
3. **仪表盘看着是满格**：轨道色用了 `--line`，在 ¥5 档等于金色，和值弧同色 → 轨道改中性灰。
4. **热力图一格都看不清**：空格子用了 `--line`（金色），和数据格一样亮 → 空格子改 5% 中性色，数据格提亮到 42%–100%。
5. **标签星图偏在一边**：螺旋排布视觉重心偏移 → 加包围盒居中，气泡整体放大。
6. **情绪图面积糊成一片泥**：金色 36% 面积在紫底上发棕 → 改青色 24%。
7. **主分数读不出小数点**：七段管小数点间距怪异 → 主分数取整，KPI 退回等宽字体。
8. **金币 3D 翻转时消失**：rotateY(180deg) 会变成一条线 → 改成 ±7° 摆动。
9. **标签「添加」按钮挤成两行**：flex 收缩 → `flex: 1 + min-width: 0` + 按钮 `flex-shrink: 0`。
10. **1920 下内容只占中间一条**：加 `min-width:1600px` 的 `--maxw` 提升。

## 5. 无障碍 / 性能自查

- 三档位下正文都在实色卡面上，未见对比度不足；焦点环使用 `--focus` 令牌，在每档都可见。
- 全站键盘可达：滑杆原生 `input[type=range]` 带 `aria-valuetext="特效预算 ¥3.50"`；弹窗有焦点陷阱 + Esc；跳转链接可聚焦主区域。
- 图表全部 `role="img"` + 标题句 + 跑马灯有 `sr-only` 摘要。
- 动效只用 `transform`/`opacity`；`prefers-reduced-motion` 下停动效且粒子数量为 0。
- 粒子 ≤ 110，页面隐藏时暂停 rAF；首屏无字体文件、无图片请求。

## 6. 已知限制

- 数据只在本机 localStorage；换机器要自己导出 JSON。
- 一天一篇（日期即主键）。
- 字体依赖 Windows 中文环境（华文琥珀 / 华文中宋 / 思源宋体）；缺失时回落但仍保留描边造型。
- 未做 i18n，界面为中文。
