# 90 秒演示脚本

> 目标：让评委在 20 秒内笑一下，在 90 秒内相信这东西真能用。
> 建议现场：浏览器全屏（F11），缩放 100%，1440×900 或 1920×1080。开场地址 `http://127.0.0.1:5174/?fx=0#/write`。

## 开场（0:00 – 0:20）· 先装正经

停在 **¥0.00 稿纸模式**。

> 「这是我们做的日记应用。左边选日期和心情，中间写字，停笔半秒自动保存。右侧是本地分析，不联网、不调模型、零延迟。」

动作：在正文里随便写一句「今天来参加比赛，有点紧张」，停手，让对方看到「已保存」。

> 「写完之后，右边会告诉你今天是什么人格——它不是 AI，它只是数了你的感叹号。」

## 转折（0:20 – 0:35）· 亮出滑杆

指向顶栏右侧的「特效预算」滑杆。

> 「这个应用最大的问题是我们预算只有五毛钱。所以做了个滑杆——钱花到哪儿，特效就到哪儿。」

动作：按一下 **MAX** 按钮（或 `Ctrl+Shift+$`）。
画面：星星转场 + 跑马灯启动 + 标题变成艺术字 + 粒子出现（音效如果开了会「叮」一声）。

> 「这是同一个应用，一个 CSS 变量没换，只是把预算拉满了。」

## 数据（0:35 – 1:05）· 证明它是真的

点击 **数据看板**。

> 「战斗力 65 分，铂金五毛。上面六个数字全部是从那 19 篇日记里算出来的。」

动作（按顺序，每步一句话）：

1. 指情绪心电图：「缺记的日子是断开的，我们没有把没写的那天补成 0 分，那是冤枉人。」
2. 指标签星图：「气泡越大出现越多，工作 6 次，说明我这一个月只有工作。」
3. 指热力图：「近一年只写满了 19 天，这就是真实的我。」
4. 指底部跑马灯：「这行字也是真的——累计 1271 字，最长一篇 100 字，标题叫《项目终于上线了》。」

## 收尾（1:05 – 1:30）· 留个记忆点

动作：回到 **写日记**，把滑杆拖回 **¥0**。

> 「我们做了两个应用，其实是同一个。¥0 的给评审看，¥5 的给流量看。谢谢。」

如果还有时间，按 `Ctrl + Shift + $` 触发彩蛋，屏幕会弹出「全县最靓的仔」。

## 30 秒极简版

1. 打开 `?fx=5#/dashboard`（满配看板，先声夺人）：「五毛钱特效，做的是日记数据看板。」
2. 点 `¥0`：「同一套代码，零特效的样子。」
3. 拖回 `MAX`：「这就是我们的预算滑杆。」
4. 一句话收：「数据都是真算的，图表全是手写 SVG，断网也能跑。」

## 兜底预案

| 翻车点 | 现场处理 |
|---|---|
| 现场网络断了 | 应用零网络依赖，字体走本机。不用管。 |
| 数据被写乱了 | 日记本 → `载入示例`，19 篇范文一键回来。 |
| 想保留当前数据 | 日记本 → `导出 JSON`，会下载一个备份文件。 |
| 页面白屏 | 重新打开 `http://127.0.0.1:5174/?fx=5#/dashboard`（URL 就是状态，不丢）。 |
| 音效没声音 | 顶栏喇叭按钮确认打开；没音箱就直接讲「静态版」。 |
| 投影分辨率低 | 用 1440×900；再低就用 `?fx=5#/entries` 讲列表，字大。 |
| 演示超时 | 只讲 30 秒极简版的四步。 |

## 评委常问的三个问题（备好答案）

**Q：这不就是 PPT 特效吗？**
A：是，而且是故意的。但它是一层可以被关掉的皮——关掉之后是一个正常的日记应用，打开之后是一个梗。我们做的是「可控的土」。

**Q：数据是不是编的？**
A：示例数据是编的，但统计是真的。现场写一篇，看板立刻 +1，`npm test` 里 51 条单测盯着统计函数。

**Q：为什么不用 ECharts？**
A：六张图手写 SVG 一共不到 600 行，首屏 JS 只有 68KB。用图表库要多 300KB，而且很难做成「五毛钱」的样子。
