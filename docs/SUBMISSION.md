# 参赛素材清单

生成命令（改了界面之后重跑一次即可）：

```bash
npm run shots          # 先刷新 13 张原始截图
node scripts/make-assets.mjs   # 再生成封面 + 5 张提交图
```

输出目录：`output/submission/`

## 对应表单字段

| 表单字段 | 用哪个文件 | 尺寸 | 体积 |
|---|---|---|---|
| 封面图片（必填） | `00-封面-五毛钱人生仪表盘.png` | 1920×1080 | 1.2 MB |
| 封面（若被裁成宽条） | `00-封面-横幅备选.png` | 1920×620 | 814 KB |
| 项目截图 1/5 | `01-写日记-五毛钱MAX.png` | 1440×900 | 675 KB |
| 项目截图 2/5 | `02-数据看板-五毛钱MAX.png` | 1440×900 | 675 KB |
| 项目截图 3/5 | `03-数据看板-极简档.png` | 1440×900 | 115 KB |
| 项目截图 4/5 | `04-写日记-极简档.png` | 1440×900 | 137 KB |
| 项目截图 5/5 | `05-日记本-五毛钱MAX.png` | 1440×900 | 676 KB |

全部满足表单限制：封面支持 SVG/PNG/JPG/GIF ≤ 5MB；截图 1–5 张、PNG/JPG、单张 ≤ 5MB。

## 为什么是这个顺序

评委大概率只会滑一遍缩略图，所以按「先亮功能，再亮反差」排：

1. **写日记**（满配）——先是能干活的证据。
2. **数据看板**（满配）——最抓眼的一张。
3. **数据看板**（极简）——紧接着放同一页的 ¥0 版本，反差在这一步炸开。
4. **写日记**（极简）——证明极简不是一张 P 图。
5. **日记本**（满配）——补上管理和搜索。

## 可直接抄的图注

- `01` 写下当天日记，停笔 0.4 秒自动保存；右侧"本地玄学分析"统计标点、情绪词与人格标签，0 token、不联网。
- `02` 数据看板：人生战斗力仪表 + 4 个 KPI + 6 张手写 SVG 图表 + 跑马灯，全部由日记实时聚合。
- `03` 同一个看板把"特效预算"调回 ¥0.00：六套视觉令牌共用一套 DOM，切换只换 CSS 变量。
- `04` ¥0.00 极简稿纸模式：方格纸、朱红页边线、宋体标题，正经到可以单独拿去做作品集。
- `05` 日记本：按月分组、关键字搜索、二次确认删除、导出 JSON、一键载入示例。

## 如果系统把封面裁得很扁

表单调色板里的封面预览常被裁成 3:1 左右。两种情况：

- 预览保留了完整比例 → 用 `00-封面-五毛钱人生仪表盘.png`。
- 预览被裁成宽条、标题被切掉 → 换 `00-封面-横幅备选.png`，标题和截图在同一水平带里，怎么裁都还有内容。
