# 设计说明

## 1. 核心判断

提示词只有三样东西：**日记 + 数据看板 + 五毛钱特效**。

如果只做一样东西，会得到两种失败结果：

1. 只做日记和看板 → 一个正常的效率工具，评委记不住。
2. 只做五毛钱 → 笑点十秒钟用完，剩下五十秒评委在看一个丑界面。

所以做成了**一根价格滑杆**：¥0.00 是正经日记应用，¥5.00 是暴走。对照本身就是节目效果，同时证明了「会做美的」和「敢做土的」是同一批人。

滑杆不是装饰，它是内容——刻度是钱，不是数字。

## 2. 六级视觉令牌

一套 CSS 变量（`src/styles/tokens.css`），`<html data-fx="...">` 切换。业务组件里**没有任何一行**「如果档位大于 X」的判断。

| 预算 | 档名 | 背景 | 标题字体 | 按钮 | 动效 |
|---|---|---|---|---|---|
| ¥0.00 | 稿纸模式 | 米色方格纸 + 朱红页边线 | 思源宋体 Heavy | 墨线描边 | 无 |
| ¥0.50 | 打印版 | 纸张投影 | 华文中宋 | 细边 + 压印 | 150ms 过渡 |
| ¥1.00 | 加亮 | 浅金渐变 | 华文新魏 | 金色渐变 | 卡片微投影 |
| ¥2.00 | 烫金 | 深蓝 + 金网格 | 华文琥珀 | 金属浮雕 + 冷光 | 金色标题发光 |
| ¥3.50 | 彩灯（默认） | 蓝紫渐变 + 旋转放射线 | 华文琥珀 | 玻璃高光 + 彩虹边 | 星星粒子 / 跑马灯 |
| ¥5.00 | 五毛钱 MAX | 品红渐变 + 金色 3px 描边 | 华文琥珀 | 立体挤出 + 抖动 | 星星转场 / 彩蛋 |

### 关于字体的一次返工

第一版标题用的是**华文彩云**——它确实是「五毛钱艺术字」的灵魂字体。但它是**空心描边字**，在大字号下还好看，一旦叠上白色描边和 18px 的字号，就变成一坨白块（`analytics-big` 和品牌名最先暴雷）。

所以改成：

- **正文标题一律用华文琥珀**（实心、圆胖、厚重），靠「彩虹渐变 + 白描边 + 硬投影」做出艺术字效果；
- 描边只给**大字号**（`≥ 28px`）加，小字号只上渐变和一层薄投影；
- 品牌名 15.5px 直接回退到无衬线 800 字重，不再参与艺术字体系。

结论：**风格可以丑，但不能读不清**。

### 关于数字字体

`Digital-7 Mono`（七段数码管）只在**主分数**（118px）上使用——那是全场最大的一处「液晶屏」。KPI 小数字退回等宽字体，因为七段管的 8/3、1/7 在小字号下会看错，数据看板不能有歧义。

## 3. 数据是真的

看板上每一个数字都来自 `src/lib/stats.ts` 的纯函数，51 条单元测试盯着它：

- **连续天数**：必须延续到今天或昨天，否则归零（不把断更算成战绩）。
- **情绪指数**：六种心情各自有 0–100 分值，按篇平均。
- **战斗力**：篇数、连续、字数、情绪稳定性、标签多样性五块加权，封顶 100，段位从「青铜五毛」到「宇宙五毛」。
- **情绪心电图**：缺记的日子**断开**而不是补零——补零会把「没写」画成「难过」。
- **关键词**：无词典 2–4 字滑动窗口 + 虚词过滤 + 子串去重。它确实会出错，所以界面上写着「本地玄学分析 · 0 token · 0 延迟 · 不联网」，不装。

## 4. 五毛钱的执行标准

「故意的土」和「做砸了的土」在评委眼里是两件事。所以每一档都守三条：

1. **文字对比度 ≥ 4.5:1**：渐变背景上不放正文，正文一律有实色卡面垫底（高价位卡面是 `rgba(28,0,46,.74)` 的暗玻璃）。
2. **焦点环不能被吃掉**：`:focus-visible` 用令牌里的 `--focus`，在每一档都保持高对比。
3. **动效只做 transform / opacity**：粒子 ≤ 110 个，`document.hidden` 时暂停，`prefers-reduced-motion` 时只保留静态造型。

低档位（¥0 / ¥0.5 / ¥5 之外）跑马灯不跑、转场不出现、粒子为 0——钱没花到那儿。

## 5. 图表

六张图全是手写 SVG，跟着主题变量走（`var(--accent)` / `var(--ink-3)`），所以切档位时图会自动换色：

| 图 | 类型 | 关键设计 |
|---|---|---|
| 情绪心电图 | 折线 + 面积 | 缺数据断线；末点加粗并直标数值 |
| 每日字数 | 柱状 | 柱顶直标；最高值加虚线框 |
| 心情构成 | 甜甜圈 | 中心放总篇数；图例带次数 |
| 标签星图 | 气泡 | 黄金角螺旋 + 碰撞检测 + 包围盒居中，刷新结果一致 |
| 记录热力图 | 日历热力 | 近一年 52 周；空格子几乎不可见，让数据自己发光 |
| 人生战斗力 | 半圆仪表 | 灰色轨道 + 彩色值弧 + 指针 |

每张图都有 `role="img"` + `aria-label`/`<title>` 的一句话结论，没有图的空态给「去写一篇」而不是空白。

## 6. 音效

WebAudio 实时合成（`src/lib/sound.ts`），没有任何音频文件：叮、噗、风、号角。默认静音，开关在顶栏。现场没音箱也不丢人。

## 7. 已知取舍

- **一天一篇**：`date` 就是主键。多篇会让列表和统计复杂一倍，收益很低。
- **无后端**：数据只在 localStorage。给了导出 JSON 和「载入示例」，现场翻车可以一键复原。
- **不接大模型**：「AI 分析」是本地统计。接在线模型会带来断网、超时、Key 失效三种现场事故，不值得。
- **字体依赖本机**：华文琥珀、华文中宋、思源宋体都在 Windows 中文环境自带。换机器会回落，但造型靠 CSS 描边保证不塌。
